## 二、六维匹配度打分

每维 1–5 分，满分 30。**严格按 JD 真实要求评，不打人情分。**

| 维度 | 看什么 |
|---|---|
| 学历与院校门槛 | 是否卡 985/211、是否卡硕士 |
| 专业匹配度 | 经济统计 / 数理背景是否被接受 |
| 技能匹配度 | SQL、数据工具、AI 工具 |
| 实习经历相关度 | AI 相关实习是否被认可 |
| 英语要求 | **是否卡六级**（她目前只有四级） |
| 方向契合度 | 真的 AI，还是挂名 |

分档：

| 总分 | 动作 |
|---|---|
| 24–30 | 优先投，重点准备，定制简历 |
| 18–23 | 正常投，批量处理 |
| 12–17 | 有空再投，不花时间定制 |
| < 12 | 不投 |

**例外规则：**「是否真 AI」= 挂名的，无论多少分都降一档。「卡六级吗」= 是的，直接降到「有空再投」以下——除非这个岗真的非常想去，那就先投，同时准备六级。

## 三、去重规则

- **唯一键** = 公司名 + 岗位名称
- **公司名规范化**：去掉「有限公司 / 股份有限公司 / （上海）/ 投资有限公司」等后缀再比对
- **岗位名规范化**：去掉「（实习生）/（2027届）/ 校招 / 急招」等后缀再比对
- 完全匹配 → 跳过
- 同公司不同岗位 → 可收录
- 每天写入前，必须先读取全表历史数据建立去重集合，并记录今日跳过数

## 四、硬规则

1. **不编造岗位。** 来源不明、链接打不开的，宁可不收。
2. **链接必须真实可访问。** 这是底线。
3. **薪资、截止日期查不到就写「未披露 / 未标注」，不要猜。**
4. **信息不足以判断某一项时，写「信息不足」，不要编。**
5. **Excel / 表格只追加，永远不删历史数据。**
6. 中小民企入选时，在「公司档位」或备注里简述它的核心优势。

## 五、隐私提醒

如果要把累积表分享给别人（同学、朋友），**先删掉「匹配点分析」和「投递建议」两列**。这两列会间接暴露你的完整画像（学校层次、英语短板、真实短板）。

自动化 prompt 和档案文件里，**不要放身份证号、银行卡号**。手机号也建议不放进公开仓库。
