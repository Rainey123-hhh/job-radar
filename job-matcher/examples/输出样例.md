## 样例一 · 评估一个岗位（模式 B）

**输入：** 一段 JD 原文

**输出：**

### 一、岗位卡片

| 项 | 内容 |
|---|---|
| 公司 / 业务线 | 某外资 AI 数据公司 · 中国区 |
| 岗位名称 | AI 产品助理（校招） |
| 工作城市 | 上海 · 徐汇 |
| 网申链接 | （真实链接） |
| 投递截止 | 2026-10-15 |
| 是否接受 2027 届本科 | 是 |
| 是否真的 AI 相关 | 是（做企业级知识库产品） |

### 二、匹配度评分

| 维度 | 分数 | 理由 |
|---|---|---|
| 学历与院校门槛 | 4/5 | 未卡 985/211，明确写「本科及以上」 |
| 专业匹配度 | 4/5 | 未限专业，注明「统计/数理背景优先」 |
| 技能匹配度 | 4/5 | 要求 SQL + 会用 AI 工具，都对得上；Python 只要求基础 |
| 实习经历相关度 | 5/5 | JD 提到「有 Agent / 自动化工作流经验优先」，壹沓那段直接命中 |
| 英语要求 | 2/5 | **要求六级 500+，目前只有四级** |
| 方向契合度 | 5/5 | 确实是 AI 应用层产品，不是挂名 |
| **总分** | **24/30** | |

**结论：建议投递** —— 六维里五维都很好，AI 相关经历直接对口，属于少见的高契合岗位。

### 三、风险与建议

1. **最可能卡住的硬门槛：英语。** JD 明确写了六级 500+，目前没有六级成绩。这一项过不了，前面再匹配也没用。
2. **简历上把壹沓那段放最前面**，并且要把「独立编写 AI skill」写在第一行——这是这个岗位最想要的经历。
3. **投递前必须做的两件事：**
   - 把 GitHub 链接加进简历（目前简历上没有，而 JD 写了「有可展示成果优先」）
   - 在简历里补一句六级的状态（比如「CET-6 备考中，2026 年 12 月」），坦诚比回避好

### 四、信息不足提示

- 薪资：JD 未披露 → 查不到，不猜
- 团队规模：信息不足，需要面试时问
